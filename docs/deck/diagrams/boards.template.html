What is new about it
01
Every flag is arguable. The reason and the method that produced it travel with the score, so an officer can disagree with it on the evidence rather than obey or ignore it.
02
A model that abstains. Gemini was chosen over embeddings because it can answer "Other" instead of forcing a nearest sector — which is what made peer groups mean anything.
03
Population statistics stay at population grain. An agency's year-end burst never becomes any one invoice's risk. No model output ever becomes a risk number.
04
Provenance is checked, not asserted. Reconciled against the ministry's own endpoints nightly, with our error and upstream lag reported separately.
05
It states what it cannot know. MPLADS publishes no progress %, beneficiary count or geo-tag, and the system says so instead of inventing them.

Feasibility — challenges — how each is already handled
Feasible today
01
It is already built and running. Live site, live API, nightly refresh unattended.
02
Public data only. No new collection, no ministry integration needed to start.
03
Free to run. Scoring is offline and deterministic; labels are cached and committed, so a clone needs no API key.
04
Commodity infrastructure. One Postgres, one serverless API, one static front end.
{{tests}}
tests against the live database
Real challenges
01
No bulk export from MoSPI. Works sit behind an OTP-gated citizen form, one member at a time.
02
A score can be mistaken for an accusation by a reader, a reporter, or an MP.
03
The record is thin. No progress %, beneficiaries, geo-tag or bill value is published.
04
Peer groups were meaningless while 98.1% of works carried one category.
05
Free-tier limits. 512 MB database; a 300→457 MB blowup happened once.
How each is handled
→
Load the aggregator's export, then reconcile to MoSPI's own endpoints nightly and publish both hops separately.
→
Every flag carries the method that produced it; a whole page states what the system refuses to claim.
→
Blind spots are listed on the site rather than filled with invented fields.
→
A language model that can abstain labels the sectors; "Other" fell from 74,676 works to 7,464.
→
Derived tables are rebuilt, never row-updated, and swapped in one transaction.
